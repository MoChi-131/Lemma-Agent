# v1.1.0

## Release summary

This release finalizes the streamlined Supermama retrieval agent. It retrieves governed Lark knowledge through a Registry-first workflow and can return visual evidence from Lark images and embedded whiteboards.

## Added

- Native Lark image-block retrieval as MCP image content.
- Embedded Lark whiteboard rendering as JPEG MCP image content.
- Support for the Lark `board` block payload used by embedded whiteboards.
- A concise operational instruction set for Registry-first retrieval, Wiki fallback, Google Drive links, approved external sources, and minimum conflict checks.

## Changed

- MCP server health and startup metadata now report version `1.1.0`.
- Retrieval documentation reflects the current lightweight Registry eligibility gate.

## Removed

- Legacy detailed metadata-validation module, optional validation MCP tool, and related test command from Lemma-Agent.
- The `ENABLE_VALIDATION_TOOLS` environment setting.

Detailed validation and correction reporting are owned by the separate Knowledge Base Management Agent.
